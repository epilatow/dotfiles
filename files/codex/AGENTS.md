# Agent instructions

Please read these global instruction files from `~/.codex/`, not from the
current repository:

1. `~/.codex/SHARED.md`
2. `~/.codex/SHARED-PRIVATE.md`

At the start of the session, also read `~/.codex/DEVELOPMENT_SHARED.md` and
`~/.codex/DEVELOPMENT_SHARED_AGENT.md`, except for either one the current
repository's own instructions already load. A repo-shared consumer loads its
own pinned copies, and reading the global ones too would mix two versions.

Treat the files as one instruction set. Where they define precedence, apply the
more specific guidance as directed.
